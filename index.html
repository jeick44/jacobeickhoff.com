Engagement 01Customer Intelligence

A map of dots gets looked at. A number for the spot somebody pointed at gets argued with.

Leadership had only ever seen its customer base as rows in an export. The tool that changed that ran on one idea: select an area, see real numbers for it.

Why the readout shows its arithmetic. A colour scale is a conclusion presented as an observation. Hovering a location shows the subtraction, so the disagreement happens over a rate or a balance, where it can be settled.

Engagement 06MacroSenseSelf-directed

An allocation process that can be replayed, argued with, and shown to be wrong.

A two-layer system built and run end to end by one person: it fetches, classifies the macro regime, allocates across fifteen funds, and writes itself a plain-English briefing, on a timer.

Why there is no return figure here. The history it can be tested over is fifty-six trading days. A ratio annualised from that describes the window, not the system, so this is published as architecture.

Engagement 04The ResearchFaculty-advised

A pass bar written down before any detector ran, and a study allowed to come back empty.

Whether AI-edited language in SEC filings predicts abnormal returns. The first question is whether that editing can be seen at all, so every detector has to clear the Gate before it may score a real filing.

Why it was rebuilt. I withdrew my own published first result after finding three defects in it. If no detector clears the bar, that is the finding, and the bar is not lowered.
